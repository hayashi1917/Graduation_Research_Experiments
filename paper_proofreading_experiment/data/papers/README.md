# 論文ファイル配置場所

このディレクトリに、実験対象の論文ファイルを配置してください。

## ディレクトリ構造

各論文IDごとにディレクトリを作成し、PDFとTeXファイルを配置します：

```
papers/
├── paper001/
│   ├── paper001.pdf
│   └── paper001.tex
├── paper002/
│   ├── paper002.pdf
│   └── paper002.tex
├── paper003/
│   ├── paper003.pdf
│   └── paper003.tex
...
└── paper010/
    ├── paper010.pdf
    └── paper010.tex
```

## ファイル命名規則

- ディレクトリ名: `{paper_id}` (例: `paper001`)
- PDFファイル: `{paper_id}.pdf` (例: `paper001.pdf`)
- TeXファイル: `{paper_id}.tex` (例: `paper001.tex`)

## 注意事項

1. **論文ID**: 論文IDは一意である必要があります
2. **ファイル形式**: PDF と TeX の両方が必要です
3. **バックアップ**: 実験前に必ず元のファイルをバックアップしてください
4. **著作権**: 論文の使用許可を確認してください

## 論文の入手先

- arXiv: https://arxiv.org/
- 情報系の国際会議論文（PDFとTeXソースが公開されているもの）
